There is no site-wide base template in this project (each page is standalone HTML), so this partial is the single place the pixel lives: edit it once and every page follows. The ID comes from the TIKTOK_PIXEL_ID environment variable via the store.context_processors.tracking context processor, so the same code runs against a test pixel locally and the live pixel in production. If the variable is unset the block renders nothing at all, which keeps development traffic out of the client's ad reporting. Only the pixel ID appears here. The Events API access token is secret and stays server side in store/services/tiktok.py.
